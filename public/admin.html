CAPA 1 // WEB PRINCIPAL + MOTOR DEL COMITÉ IA (ESTE REPO) ~€4.50/mes

Despliega la raíz de este proyecto (Dockerfile + docker-compose.prod.yml) en un VPS ligero de Hetzner Cloud (CX22), Netcup o directamente en Railway / Coolify. Incluye Caddy 2 que emite el certificado HTTPS para talentup.cloud de forma 100% automática.

CAPA 2 // NODOS DE CÁPSULAS PARA CLIENTES (COOLIFY / TRAEFIK) €29.90/nodo

Para alojar las aplicaciones Open Source de tus clientes (Twenty CRM, Plane, Odoo, Mattermost), contrata nodos Netcup RS 8000 EPYC (16 vCPU / 64GB RAM NVMe en Nuremberg por 29,90€/mes) o Hetzner Dedicated con Coolify instalado. Cada servidor de 64GB RAM aloja entre 35 y 50 cápsulas de clientes aisladas.

CAPA 3 // DNS COMODÍN + FACTURACIÓN AUTOMÁTICA 100% Automático

En Cloudflare DNS apunta A *.talentup.cloud a la IP de tu clúster Coolify/Traefik. Así cualquier subdominio que pida un cliente (acme.talentup.cloud) tendrá TLS instantáneo. Conecta Stripe Billing para cobrar la cuota mensual exacta.
